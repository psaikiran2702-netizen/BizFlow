# BizFlow - Business Management Platform

BizFlow is a responsive business management web application designed to provide a simple and modern interface for managing clients, services, projects, business statistics, and customer enquiries.

## 🚀 Live Project

Coming soon...

## 📌 Project Overview

BizFlow is a multi-page frontend project built to demonstrate practical web development skills using HTML, CSS, Bootstrap, and JavaScript.

The project includes a business dashboard, client management system, service filtering, contact form validation, responsive design, and browser-based data storage.

## ✨ Features

- Responsive multi-page website
- Modern business landing page
- About Us page
- Services page with category filtering
- Business dashboard
- Revenue analytics chart
- Project status chart
- Project search functionality
- Client management system
- Add and delete clients
- Client search functionality
- LocalStorage data persistence
- Contact form validation
- Indian mobile number validation
- Message character counter
- Dynamic statistics
- Responsive mobile navigation
- Custom favicon

## 📄 Pages

| Page | Description |
|------|-------------|
| Home | Business overview and key statistics |
| About | Company information, mission, vision and values |
| Services | Services with category-based filtering |
| Dashboard | Revenue, projects and business analytics |
| Clients | Client management and search |
| Contact | Customer enquiry form with validation |
